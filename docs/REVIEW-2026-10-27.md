# 管理器开源前审查记录 · 2026-10-27

范围：Lite 管理器 0.3.1 的 C# 源码、构建入口、测试入口和公开资料。此记录是项目发布前检查，不是独立第三方安全审计，也不覆盖未公开内核源码的完整审计。

## 本次修正

原构建脚本假定 `preview/`、`evidence/` 已存在，新克隆的仓库会无法输出程序。现改为自动创建目录，并支持指定正式与 QA 输出目录，以免覆盖正在使用的安装。

新增独立测试脚本，显式传入运行时目录；生成新的测试身份，拒绝使用真实环境。README 中提供仅作用于当前 PowerShell 进程的执行策略参数，不修改系统执行策略。

本次没有修改管理器功能代码，没有重新编译内核。官网原有 0.3.1 完整包仍适用；从公开源码重新编译 Windows 管理器已成功。

## 已审查的关键路径

| 范围 | 核对内容 |
| --- | --- |
| 浏览器启动 | 独立环境目录；参数按 Windows 规则引用；启动不使用命令解释器；正式参数不带调试端口或沙箱关闭开关 |
| 环境保存 | 配置来源与 GUID 校验；当前用户 DPAPI 加密；文件替换保存；复制配置不复制网站数据 |
| 内核加载 | 固定清单哈希、各组件大小与哈希、路径范围和链接检查；校验后启动 |
| 永久删除 | 所属目录标记、路径与链接检查、进程及文件占用检查；删除前保存中间状态；不影响其他环境 |
| 网络导入 | 输入大小/行数限制；导入预览；线路去重；HTTPS 订阅限制与超时；凭据加密保存 |
| 网络进程 | 固定组件哈希；配置通过标准输入传递；仅监听回环地址；节点启动失败阻止浏览器启动 |
| 备份恢复 | 当前用户加密；内容大小与数量限制；路径越界和重复条目检查；恢复到新环境 |
| 界面状态 | 浏览器退出后的按钮恢复；空白点击及不变状态不触发列表重复重绘 |
| 发布内容 | 仅列入管理器源码、必要脚本、文档和示例截图；排除部署脚本、账号资料、内核源码、运行时二进制及本机诊断记录 |

源码中的示例用户名、密码、UUID 和回环地址只用于合成测试，不是真实账号或节点。静态扫描覆盖私钥、常见访问令牌格式及本机私有路径；扫描不能证明不存在所有类别的问题。

## 已知限制

- 内核修改源码未公开，第三方不能从此仓库复现整个内核构建。
- Windows Forms 与 DPAPI 依赖 Windows；没有 macOS/Linux 发行包。
- 备份仅限同一 Windows 账户解密，单次最大 256 MB；不提供跨电脑登录状态迁移。
- 当前没有自动更新，内核清单和组件哈希采用固定版本。
- 网站数据不是整个目录加密；同一 Windows 用户身份运行的程序不在 DPAPI 隔离边界内。
- 节点服务器域名可能使用系统 DNS；不承诺完全匿名、防关联、免 KYC 或网站账号不被限制。
- OVH 部分页面的用户感知卡顿仍在跟踪；没有将局部性能测试结果表述为所有网站都流畅。
- 尚未全面覆盖另一台电脑、真实混合 DPI 多屏、所有外部代理和所有网站。
